# 🧭 Development Philosophy

I don't believe being a developer means knowing everything.

Software development is often just being comfortable with not knowing something yet.

For me, the process usually looks like this:

* Understand the problem.
* Understand how the system works.
* Research what I don't know.
* Build something.
* Discover that something is broken.
* Debug it.
* Understand why it broke.
* Improve the architecture.
* Repeat.

Every bug teaches something.

Every failed experiment gives context.

Every finished project makes the next one slightly better.
